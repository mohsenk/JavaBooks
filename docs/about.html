About this list

Awesome Java Books started in 2024 as a small GitHub list and has grown into a curated guide covering {% assign total = 0 %}{% for cat in site.data.books %}{% assign total = total | plus: cat.books.size %}{% endfor %}{{ total }}+ books across {{ site.data.books | size }} skill tracks. This page explains how books get on the list — and how they get taken off.

How we choose books

Every book on this site is evaluated against the same criteria before it's added:

  • Technical accuracy — the content has to be correct and, where relevant, current with modern Java (17+).
  • Teaching quality — clear explanations, good examples, and a structure that matches how the topic is actually learned.
  • Staying power — does it teach durable concepts, or will it be obsolete in a year?
  • Track fit — is it genuinely useful at the level we've placed it in (beginner / intermediate / advanced), based on its actual prerequisites?

We deliberately keep each category short rather than listing every Java book that exists. A list of 40 "good enough" books is less useful than a list of 6 genuinely great ones.

What we won't do

We don't accept payment to list, rank, or favorably describe a book. Outbound retailer links are plain, unpaid links today; if that ever changes, this page will say so.

How the list is maintained

This site is open source. Book descriptions, categories, and rankings live in a single data file in the GitHub repository, and changes are tracked in version control. If you spot an outdated edition, a broken link, or think a book deserves a spot, open an issue or pull request — see the contributing guide.
